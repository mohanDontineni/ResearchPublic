# Sharing notes

This is a deliberately selected research artifact, not a complete ResearchOS backup.
The selection includes executable analysis, public acquisition manifests, derived
results and PNG figures. It excludes manuscript drafts, private notes and chats,
application integration scripts, author metadata, unpublished submission forms,
raw provider datasets and reading-copy PDFs.

Original source files and JSON/CSV result values are unchanged. Image metadata is
removed by the sharing service. Instructions describe the reproduced study and
its limits; no scientific result is added by the packaging step. Review the manifest
and the files before publishing a release. The app's Public Sharing tab requires
workspace login and does not itself publish an external repository or DOI.
